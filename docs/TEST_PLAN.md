# 시험 계획

> 상태: **v1 (2026-10-04)**. 기준선 **676/0** → 1차 구현 뒤 **725/0**(`node tools/test.mjs`, Linux · Node 22.22.0).

## 1. 돌리는 법

```bash
node tools/test.mjs          # 스스로 SE2_MOCK=1 · 임시 SE2_DATA_DIR · 포트 8899 를 쓴다. 망·구독·키를 쓰지 않는다
```

- 시험은 호스팅 설정(`SE2_HOST`·`SE2_ACCESS_KEY`·`PORT` …)을 시작할 때 지운다 — 늘 로컬 개인판 꼴로 돈다.
- 윈도에서만 도는 칸(설치 줄을 실제로 돌리기)은 다른 OS 에서 건너뛴다.
- GitHub Actions(`.github/workflows/test.yml`)가 push·PR 마다 같은 명령을 돌린다.
- 온라인판: `npm ci` 후 `DATABASE_URL_TEST=postgres://…/<이름>_test node online/test.mjs` — 실제 PostgreSQL 로 돈다.
  이름이 `_test` 로 끝나는 DB 에만 붙는다(스키마를 지우고 다시 짓기 때문). CI 는 PostgreSQL 16 서비스 컨테이너로 돌린다.

## 2. 규칙

1. **기존 시험을 지우지 않는다.** 구조를 옮겨 소스 무늬 검사가 깨지면 **같은 규칙을 새 자리에서** 검사하도록 고친다(보호를 줄이지 않는다).
   - 1차 구현에서 고친 한 줄: «기본 포트는 8801» 이 `server.mjs` 의 글자 `Number(process.env.SE2_PORT || 8801)` 를 찾던 것을
     **동작 검사**(`resolveHosting({}).port === 8801` · 실행기가 `SE2_PORT` 를 못박음 · `SE2_PORT` 가 `PORT` 보다 먼저 · 서버가 그 해석을 씀)로 바꿨다. 뜻은 같고 더 단단하다.
2. 기능 하나 = 시험 하나 이상. 버그를 고치면 그 버그를 재현하는 시험부터.
3. 망·실제 키·실제 DB 없이 도는 것이 기본. 바깥이 필요한 시험은 환경 변수가 있을 때만 돈다(`DATABASE_URL_TEST`, 수동 연기 시험).
4. 비밀값은 시험 코드에도 픽스처에도 넣지 않는다(가짜 값만).

## 4. 단계별로 더할 시험 (명세 §77 대응)

### Core (Sprint 2)
- 문서 생성 · 판 · 복원 · 확정본 · 참조 · **참조 중복 제거** · 논의 가지 · 합평 다중 에이전트(사람마다 1회 + 모으기) · 모순 검사(확정본 우선) · 휴지통
- `planCall()` 의 `inputs`(무엇을 어느 구획에 실었나 · sha256)가 실제 프롬프트와 일치
- 포트 주입: 가짜 `ProjectStore`/`Generator`/`Ids`/`Clock` 로 Core 만 돌리기

### AI Provider (Sprint 3~5)
- 어댑터별 가짜 HTTP 서버: 성공 · 스트리밍 · 401/403/404/400/413/429/5xx/529 · 잘림(`length`) · 안전 거절 · 느린 응답(timeout) · 연결 끊김 · 취소(abort)
- 계약: `generate` 는 throw 하지 않는다 · 세 어댑터의 결과 모양이 같다 · usage/cost 정규화 · **credential 이 오류 문구·로그에 새지 않는다**
- 모델 카탈로그: tier → model id 바꿔도 Core 는 그대로(명세 부록 Z 시나리오 5)

### DB · 인증 · 격리 (Sprint 6~8, 10~12) — `DATABASE_URL_TEST` 가 있을 때
- **(있음)** 프로젝트 저장소 왕복(`online/test.store.mjs`): Core 연산을 메모리 덩어리에 걸고 표에 쓴 뒤 다시 지어 견준다 — 작품 칸 · 카테고리 · 문서/판/복원/확정본 · 참조 · 에이전트 · 스레드 가지 · 프롬프트 층 · 휴지통(되살리기 · 영구 삭제는 purged_at) · 껍데기 거두기 · 자료 옮기기 · 판 상한(덩어리는 20, 표는 모두) · 실패 시 아무것도 안 씀 · 동시 고침 10건 무손실 · 사람별 목록
- 마이그레이션 처음부터/한 단계씩 · JSON 가져오기(수량·sha256 대조 보고서) · 끊긴 참조 걸러 내기
- 로그인/로그아웃/세션 만료 · 비밀번호 해시 · 속도 제한
- **다른 기관 프로젝트 접근 차단** · 다른 사용자 프로젝트 접근 차단 · 잘못된 `project_id` 직접 호출 → 404 · 강사는 맡은 수업만
- 라이선스 만료/정지 → 새 AI 작업 거절(편집·열람은 정책대로) · 권한 없는 라이선스 조작 거절
- API Key 원문이 어떤 응답에도 없다(응답 전수 검사) · 감사 로그가 남는다

### Job (Sprint 9)
- 중복 등록 거절 · 두 worker 동시 claim · lease 만료 회수 · 울타리(좀비 worker 저장 거절) · 취소 · 일시중지(다음 호출 앞) · 체크포인트에서 잇기 ·
