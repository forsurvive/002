# 작법서 자리

이 폴더의 `.txt` 를 `tools/books.mjs` 가 프로그램이 올라올 때 한 번 읽어,
프로젝트를 만들 때 «가리키는 문서»(`doc.src`)로 세운다. 본문은 프로젝트 파일에 베끼지 않고
부를 때 `model.bodyOf(d)` 가 푼다 — 그래서 십만 자 책이 상태 전송을 한 글자도 굵히지 않는다.

**지금은 비어 있다**(사용자 지시, 2026-09-22). 까닭은 DESIGN.md 를 보라 —
남의 책 요약본을 프로그램에 실어 두지 않는다(저작권).
집필의 잣대는 프로젝트를 만들 때 지어지는 에이전트 프롬프트(`project.agents`)가 든다.

비어 있어도 프로그램은 선다 — `bookList()` 가 빈 표를 돌려주고 작법서 구획이 서지 않는다.
