이 서비스

자료와 창작 판단을 문서로 쌓고, 문서와 판(이력)을 참조하며 단계마다 글을 쓰는 작업 도구입니다. AI 가 대신 써 주는 것이 아니라, 사용자가 만든 맥락을 잃지 않게 하며 다음 글을 돕습니다.

전자책을 쓰는 걸음

  • 책 의뢰 · 자료 → 자료 분석 → 책의 설계(독자 · 약속 · 분량 · 구성과 그 근거) → 목차 · 장 카드 → 장 집필 → 전권 검토 · 개정 계획 → 서문(자료 분석이 필요하다고 볼 때) → 완성
  • 걸음마다 사람이 생성 · 검토 · 수정 · 승인합니다. 결과는 늘 새 판으로 쌓이고 이전 판은 이력에 남습니다.
  • 사실 · 수치는 넣은 자료에서만 쓰고, 근거가 없으면 [확인 필요]로 표시합니다.

이야기를 쓰는 걸음

  • 작품 규격 · 자료 → 자료 분석 → 세계관 → 기획서 → 인물 → 플롯 → 회차 · 장면 → 본문 → 완성
  • 걸음마다 사람이 생성 · 검토 · 수정 · 확정합니다. 결과는 늘 새 판으로 쌓입니다.

AI 와 비용

AI 기능은 사용자가 «내 계정»에서 고른 AI 회사(Claude · ChatGPT · Gemini)의, 사용자가 넣은 API 키로 실행되며, AI 사용 요금은 사용자가 그 회사에 직접 냅니다. 서비스 이용권(월 정기결제)은 따로입니다 — 가입하면 2일 동안 무료로 써 볼 수 있습니다.
